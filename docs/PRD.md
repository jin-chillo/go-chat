## 1. 제품 개요

### 1.1 배경
실시간 채팅 기능과 인증 시스템은 현대 웹 애플리케이션의 핵심 구성 요소입니다. 이 프로젝트는 Go 언어를 활용하여 이러한 기능을 직접 구현함으로써 백엔드 개발 역량을 증명하는 포트폴리오 프로젝트입니다.

### 1.2 제품 정의
GoChat은 JWT 기반 인증과 WebSocket 실시간 채팅 기능을 제공하는 Go 백엔드 서버입니다.

### 1.3 목표
- Go 언어의 동시성 처리 능력을 활용한 고성능 백엔드 구현
- 실무에서 사용되는 인증 패턴(JWT, 리프레시 토큰) 구현
- WebSocket과 Redis Pub/Sub을 활용한 실시간 통신 구현
- PostgreSQL, MongoDB, Redis를 적절히 활용한 폴리글랏 퍼시스턴스 설계

## 3. 핵심 기능 요구사항

### 3.1 인증 시스템 (Auth)

#### FR-AUTH-001: 회원가입
- 이메일, 비밀번호, 닉네임으로 회원가입
- 이메일 중복 검사
- 비밀번호 암호화 저장 (bcrypt)

#### FR-AUTH-002: 로그인
- 이메일/비밀번호로 로그인
- JWT 액세스 토큰 발급 (유효기간: 15분)
- 리프레시 토큰 발급 (유효기간: 7일)
- 로그인 이력 저장

#### FR-AUTH-003: 토큰 갱신
- 리프레시 토큰으로 새 액세스 토큰 발급
- 만료된 리프레시 토큰 거부

#### FR-AUTH-004: 로그아웃
- 현재 세션 무효화
- 토큰 블랙리스트 등록 (Redis)

#### FR-AUTH-005: 세션 관리 *(v2.0 예정)*
- 동시 로그인 세션 제한 (선택)
- 다른 기기 로그아웃 기능

### 3.2 채팅 시스템 (Chat)

#### FR-CHAT-001: 채널 관리
- 채널 생성 (이름, 설명)
- 채널 목록 조회
- 채널 상세 조회
- 채널 참여/퇴장
- 채널 수정 (소유자만 가능)
- 채널 삭제 (소유자만 가능)
- 내 채널 목록 조회
- 온라인 멤버 조회

#### FR-CHAT-002: 실시간 메시징
- WebSocket 연결 수립
- 메시지 송신/수신
- 메시지 저장 (MongoDB)
- 메시지 이력 조회 (페이지네이션)

#### FR-CHAT-003: 온라인 상태
- 사용자 온라인/오프라인 상태 표시
- 채널 내 온라인 사용자 목록

#### FR-CHAT-004: 알림
- 새 메시지 알림 (WebSocket)
- 멘션 알림 (@username) *(Optional - v2.0 예정)*

## 4. 비기능 요구사항

### 4.1 성능
| 항목 | 요구사항 |
|-----|---------|
| API 응답 시간 | 평균 100ms 이하 |
| WebSocket 지연 | 50ms 이하 |
| 동시 접속자 | 100명 이상 (무료 티어 기준) |

### 4.2 보안
- 비밀번호 bcrypt 해싱
- JWT 서명 검증
- HTTPS 적용 (배포 시)
- SQL Injection 방지
- XSS 방지

### 4.3 가용성
- 단일 서버 배포 (Railway)
- 자동 재시작 (컨테이너 crash 시)

### 4.4 확장성
- 수평 확장 고려한 설계 (Redis Pub/Sub)
- 스테이트리스 서버 설계

## 7. 범위

### 7.1 포함 (In Scope)
- JWT 기반 인증 시스템
- 채널 기반 그룹 채팅
- 실시간 메시징 (WebSocket)
- 메시지 저장 및 조회
- 온라인 상태 관리
- REST API + WebSocket 엔드포인트

### 7.2 제외 (Out of Scope)
- 1:1 다이렉트 메시지 (DM)
- 파일/이미지 업로드
- OAuth 소셜 로그인
- 푸시 알림
- 관리자 대시보드
- 모바일 앱

## 8. 제약사항

### 8.1 기술적 제약
- 무료 티어 서비스 사용 (리소스 제한)
- Neon PostgreSQL: 0.5GB 스토리지, 100 CU-hours/월
- MongoDB Atlas: 512MB 스토리지
- Upstash Redis: 500K 명령/월, 256MB 데이터

### 8.2 일정 제약
- 개인 학습 프로젝트로 명확한 데드라인 없음
- 단계별(Phase) 개발 진행
